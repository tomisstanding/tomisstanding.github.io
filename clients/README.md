# Client page

Static HTML, CSS, and JavaScript. No build step. Serve the repository with any static web server and visit `/clients/`.

Edit the `clients` array in `clients.js` to add or update collaborations. Each entry supplies the name, local logo filename, category, website, company description, contribution, and services. Counts and controls update automatically. The wheel displays five clients at a time with group controls. Selecting a client in the index or moving with arrow keys automatically opens the correct group. All clients remain accessible in the static index.

Interactions: hover, click/tap, Tab, arrow keys, Home/End, previous/next buttons, and the static client index. Motion pauses during exploration, when offscreen, and in background tabs. Reduced motion starts paused; the visitor may opt in using Resume rotation.
