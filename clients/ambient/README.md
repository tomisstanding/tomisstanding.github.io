# Woodland ambient artwork

Asset: `songbird-pencil-flight.png` (1263 × 1246 transparent PNG).

Generated with the built-in image generation tool using `../wilderness-background.png` as a pencil-style reference. The four frames run in reading order; CSS compensates for the lower row's body position. The creek ripples are original SVG paths, aligned to the forest image's coordinates.

Visual research included [Dribbble water ripple references](https://dribbble.com/search/water-ripple) and [Mair Perkins's hand-drawn bird animation](https://mairperkins.co.uk/animations/hand-drawn-bird-animation). No artwork was copied from those references.

## Final generation prompt

Use case: illustration-story. Asset type: transparent 2x2 sprite sheet for a subtle website bird flight animation.
Use the supplied forest image as a STYLE REFERENCE ONLY: monochrome graphite pencil, fine scratchy hatching, natural-history illustration, irregular hand-drawn contours.
Create ONLY four drawings of the SAME realistic small songbird in flight, side view flying RIGHT, arranged in a precise equal 2x2 grid on a genuinely transparent canvas. No forest, background, branches, text, labels, grid lines or shadows.
Each square cell contains one complete bird centered at exactly the same body position and scale, with ample transparent margin around all wing tips and tail. Body axis horizontal. Body occupies about 40% of each cell width, full bird about 75% cell width. Keep beak, head, belly, tail positions registered identically between cells.
Top left: both wings raised at the top of the upstroke with individually drawn feathers. Top right: wings halfway lowered, spread diagonally backwards. Bottom left: wings at bottom of downstroke below body. Bottom right: wings halfway raised, nearly level in a brief glide.
Highly realistic bird anatomy, slender small beak, tiny eye, natural tapered tail, meticulously sketched flight feathers with delicate cross-hatching and white spaces. Dark gray graphite lines, no color, no thick black fill, no flat vector shapes, no cartoon icon, no cute giant eyes. Must look hand-drawn with the same pencil as the reference woodland. Crisp linework readable at a small displayed size. Transparent background outside bird; light paper-colored feather interiors. Four frames will play in reading order in a repeating wingbeat.
